# 수집·근거 정책

1. 세종시의회 공식 도메인의 공개 목록·문서만 수집한다. 미공개 내부 속기 원고는 입력이 아니다.
2. 최초 실행은 최신 목록의 초기 기준선을 만든다. 이후 신규·수정 자료만 변경 건으로 세며 조회 건수를 신규 건수로 부르지 않는다.
3. 원문 URL, 문서 ID, 회의일/목록 기재일, 확인일, 임시본 여부, 지문을 남긴다. 목록 날짜를 원문 최초 게시시각으로 바꾸지 않는다.
4. 원문이 바뀌면 이전 판본을 보존한다. 근거 지문이 일치하지 않는 브리핑은 현재 판본의 브리핑으로 노출하지 않는다.
5. 답변 언급, 자료 제출 수락, 제출 증빙 확인, 집행부 완료 보고, 독립적으로 확인한 완료를 구분한다. 자료 부재만으로 미이행이나 기한 초과를 판정하지 않는다.
6. 자동 발언 연결은 인접 발언의 보조 발췌다. 원문 링크를 항상 제공하며 브리핑은 검토용이다.
7. 첨부자료는 링크·제목 수집과 본문 읽기를 구분한다. 비공개 개인 사례·연락처 등은 브리핑에 옮기지 않는다.
8. 예산은 연도·회계·본예산/추경/결산·단위를 일치시킨 뒤 비교한다. 자료가 부족하면 비교와 추정을 보류한다.
9. 새로 작성한 코드만 MIT다. 공개자료와 의회 CI의 별도 오픈라이선스는 미확인이며 무단 오픈라이선스 표기를 하지 않는다.
10. 출처 실패·파싱 실패는 신규 자료 없음과 다르다. 출처별 마지막 성공과 실패 이유를 표시하고 마지막 정상 자료를 보존한다.

현재 수집 범위는 출처별 최신 목록 1페이지와 본문 수집 상한이 있는 증분 시제품이다. 전체 의회자료를 전수 수집했다는 주장을 하지 않는다. 세종시의 공개 실시간 속기 원문 제공 경로는 미확인이며, 공개 임시회의록이 확인된 가장 빠른 텍스트 입력이다.
