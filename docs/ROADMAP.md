# 의원의 회의 준비와 후속 확인을 돕는 개발 계획

제품의 중심은 ‘이 사업에서 지난번에 무엇을 물었고, 집행부는 무엇을 답했으며, 다음에 어떤 자료를 확인할 것인가’입니다. 세종시의회 업무 흐름을 기준으로 개발합니다.

## 0.4에서 제공

최신 회의에 연결할 실무 비교자료만 남기는 선별·원문 재검증, 공개 읽기 전용 화면, GitHub 소스, 매일 18:00 수집·색인 커밋·배포, 종류·날짜·키워드 검색, 참고함, 근거 포함 질의 복사·보관·내려받기·인쇄를 제공합니다. 임시본/정식본, 원문 판본, 실제 발언과 AI 작성 초안, 약속과 이행 증빙을 구분합니다.

## 다음 개발 순서

| 순서 | 의원에게 생기는 변화 | 구현 | 완료 기준 |
| --- | --- | --- | --- |
| 1 | 사업 하나에서 관련 자료를 함께 봄 | 의안번호·사업명·소관부서로 회의록/의안/검토보고서/예산·결산 연결 | 연결마다 공식 URL과 연결 이유 표시. 자동 연결을 사람이 수정 가능 |
| 2 | 예산 숫자와 근거 쪽을 바로 확인 | 공개 HWPX/PDF 우선, 표·쪽·금액 단위를 보존. HWP 변환 실패 표시 | 인용마다 문서·쪽/절·표 머리글·단위 제공. 누락을 숨기지 않음 |
| 3 | 자료 제출 약속을 후속 확인 | 제출 항목·담당 부서·원문 기한 추출, 실제 제출 문서·조치결과 연결 | 약속과 실제 증빙을 별도 저장. 기한 없으면 미확인. 자료 발견만으로 완료 처리하지 않음 |
| 4 | 임시본 정정의 영향을 확인 | 문단 단위 수정 비교, 영향받은 질문 표시, 검토 후 재연결 | 변경 전후와 영향 근거를 나란히 표시. 구판 질문을 자동 승인하지 않음 |
| 5 | 관심 사업의 회의자료를 한 번에 만듦 | 관심 키워드·회의별 묶음·부서별 질문지·회의 후 확인 목록 | 출력마다 수집 시각·회의일·문서 상태·원문 링크. 개인 메모 기본 비공개 |
| 6 | 반복 질의와 답변 변화를 찾음 | 회기 간 사업 검색·답변 비교·근거 누락 후보 | 발언자·회의일·원문 연결. 책임·위법·이행 여부를 자동 판정하지 않음 |

## 수집 확장

먼저 현재 공식 7종의 안정성을 다듬고, 다음으로 세종시·교육청의 공개 예산·결산·사업설명서·성과보고서·감사 조치자료를 검토합니다. 공식 공개 경로·이용 조건·갱신 방식이 검증된 출처만 추가합니다. 아직 연결하지 않은 출처를 수집 중이라고 표시하지 않습니다.

실시간 속기는 공식 공개 경로와 이용 조건 확인 뒤 추가합니다. 비공개 속기사 초안은 대상이 아닙니다. 영상 음성인식을 추가한다면 ‘잠정 자동 전사’로 표시하여 공식 기록과 구분합니다.

## 운영과 품질

공개 화면은 읽기 전용입니다. 운영자 브리핑 저장과 개인 검토는 인증된 경로에서 수행합니다. AI 브리핑의 GitHub 자동 동기화는 근거 검증·운영자 검토를 통과하는 별도 과정으로 추가합니다.

회의 준비 시간, 근거 누락률, 원문 수정 후 재검토 소요시간, 약속과 증빙의 정확한 연결률을 측정합니다. 사용자 검증이나 경쟁 서비스 성능 비교를 아직 수행하지 않았으므로 수치 우위를 주장하지 않습니다.
